Как считают прочность бетона по образцам

  1. Прочность образца: R = α · F / A, где F — разрушающая нагрузка, A — площадь сечения, α — масштабный коэффициент для формы и размера образца (у куба 150 мм α = 1, у куба 100 мм α = 0,95).
  2. Прочность пробы (серии) по п. 8.4 ГОСТ 10180: из 2 образцов — среднее двух, из 3 — по двум наибольшим, из 4 — по трём, из 6 — по четырём.
  3. По схеме Г ГОСТ 18105 для бетонной смеси нужно: средняя Rm ≥ 1,28 · B, и каждая проба ≥ B. Для монолитной конструкции: Bф = 0,8 · Rm ≥ B.
  4. При 3 пробах и больше проверяют коэффициент вариации: он не должен превышать граничный по табл. 3 ГОСТ 18105.
